## 概要
[CookingRecipe](https://github.com/YakohACT/CookingRecipe)をアンドロイドで動作させるために作成(つまりYakohはアンドロイドユーザー)

基本的には[CookingRecipe](https://github.com/YakohACT/CookingRecipe)と全く同じだけど、AIの部分だけ仕様がちょっと違ったりする、というか変えないとスマホでローカルAIを動かすハメになるし。

アンドロイドの仕様にあわせるのが面倒なため、Claude Opusくんに全投げしてます。そのため、なんかやらかしても基本気づかないため、バグがあったらごめん。

想定してる使い方はPCで作ったレシピをエクスポートして、スマホにインポートする感じだけど、スマホ単体でもできます。
